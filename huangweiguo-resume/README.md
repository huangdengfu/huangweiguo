# 黄伟国 · 个人简历网站

一个纯手写的单页简历网站（HTML + CSS + 原生 JavaScript，无框架、无外部依赖、离线可用），
面向「网络工程师 / 网络运维 / 技术支持」方向。

## 目录结构

```
huangweiguo-resume/
├─ index.html                  页面内容（所有文字都在这里改）
├─ assets/
│  ├─ css/style.css            样式：配色、排版、响应式、打印样式
│  ├─ js/snippets.js           Python / Java / 华为 / 思科 的代码示例内容
│  ├─ js/main.js               交互：导航、滚动动画、代码高亮、页签、复制、拓扑画布
│  ├─ img/avatar.jpg           证件照（来自原 Word 简历）
│  └─ docs/黄伟国-个人简历.docx  原 Word 简历，供「下载简历」按钮使用
└─ README.md
```

## 本地查看

直接双击 `index.html` 即可。若浏览器限制本地文件，可在该目录执行：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署（让别人能通过网址打开）

- **GitHub Pages**：新建仓库 → 上传整个文件夹 → Settings → Pages → 选择 main 分支根目录。
- **Netlify / Vercel**：把文件夹直接拖到 Netlify Drop，几秒生成网址。
- **学校/公司服务器**：把整个文件夹放到 Nginx/Apache 的站点目录即可。

## 需要你本人核对 / 替换的地方

网站内容依据你的 Word 简历扩写，但下面这些是我按专业常规补的「合理细节」，**请对照真实经历调整**：

1. **项目细节**：地址规划、ACL 策略、排障步骤写得比较具体，如与你实际做的不同，请改掉，别在面试时对不上。
2. **实验清单的「熟练 / 掌握」**：按你真实情况勾选，没做过的实验建议删掉。
3. **技能百分比**：属于自评，可整体微调；数值不必太精确。
4. **期望城市 / 到岗时间**：目前写的是「南昌（可接受异地）」「可实习，毕业后全职」，按实际情况改。
5. **证书全称**：目前显示「计算机网络安全管理员 · 四级 / 中级」，如你的证书名称或等级表述不同，请改成证书上的原文。

## 两个小提醒

- **隐私**：页面上的手机号和邮箱是公开的，投递时建议用专门的求职邮箱；若长期挂在公网，可考虑把手机号换成「微信同号」等弱化写法，或加一层联系方式表单。
- **导出 PDF**：浏览器按 `Ctrl + P` → 目标选「另存为 PDF」即可得到浅色打印版（已单独写过打印样式，会自动隐藏导航与动画）。
