      地址与 VLAN 规划

      VLAN用途网段网关
      10办公192.168.10.0/24.254
      20教学192.168.20.0/24.254
      30服务器192.168.30.0/24.254
      99设备管理192.168.99.0/24.254

      出口与安全策略

      • 核心配置默认路由指向 R1，R1 做 NAT 转换后上网
      • 管理 VLAN 99 仅允许运维主机 SSH 登录，其余拒绝
      • ACL 限制教学区访问服务器区的敏感端口
      • 未使用端口 shutdown，接入口开启端口安全限制 MAC 数量

      实施步骤

      1. 规划：按区域拆分 VLAN 与网段，预留管理地址段，画出逻辑拓扑。
      2. 接入层：接入口配置 access 并划入 VLAN，上联口配 Trunk，只放行必要 VLAN。
      3. 汇聚 / 核心：三层交换机创建 Vlanif 作为各 VLAN 网关，配置静态路由 / OSPF 与出口互通。
      4. 出口：R1 配默认路由与 NAT，内网终端访问外网。
      5. 验证：同 VLAN 二层互通 → 跨 VLAN 三层互通 → 出网 → ACL 生效对比 → 断开链路观察 STP 收敛。

      排障思路

      • 先用 display interface brief 看物理与协议状态，排除线缆 / 端口问题
      • 用 display port vlan 确认 Access / Trunk 放行是否正确
      • 逐跳 ping 网关、tracert 定位断点，再查 ARP 与路由表
      • 抓包确认 VLAN Tag 是否被剥离、ARP 请求是否有去无回

      成果

      形成拓扑图、地址表、逐设备配置与验证记录；同一方案在 eNSP 与 Packet Tracer 各实现一遍，整理出 VRP / IOS 命令对照表。
